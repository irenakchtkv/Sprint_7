# Проект автоматизации тестирования "Яндекс Самокат" API

## О проекте
Проект содержит автоматизированные API-тесты для веб-приложения "Яндекс Самокат".

## Стек технологий: 
- Python
- pytest
- requests
- Allure
- allure-pytest

## Структура проекта
- tests/ - папка с тестовыми файлами
- conftest.py - фикстуры для подготовки данных (создание и удаление курьера)
- urls.py - url и эндпоинты для составления запросов
- generators.py -  генераторы случайных строк и данных курьера, функция для регистрации
- requirements.txt - список внешних зависимостей

## Установка зависимостей
Установить необходимые зависимости можно по отдельности:
- pip install pytest
- pip install requests
- pip install allure-pytest

Или все одной командой:
- pip3 install -r requirements.txt

## Запуск тестов
Команда для запуска всех тестов: 
- python -m pytest -s
Команда для запуска тестов с сохранением результатов: 
- python -m pytest --alluredir=allure_results
