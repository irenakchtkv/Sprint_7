# Проект автоматизации тестирования "Яндекс Самокат" API

## О проекте
Проект содержит автоматизированные API-тесты для веб-приложения "Яндекс Самокат".

## Стек технологий: 
- Python
- pytest
- requests
- Allure
- allure-pytest

## Структура проекта
- tests/ - папка с тестовыми файлами
- conftest.py - фикстуры для подготовки данных (создание и удаление курьера)
- urls.py - url и эндпоинты для составления запросов
- generators.py -  генераторы случайных строк и данных курьера, функция для регистрации
- requirements.txt - список внешних зависимостей
- data.py - тестовые данные для создания заказов
- README.md - описание проекта и инструкции по запуску

## Виртуальное окружение
Перед установкой внешних зависимостей необходимо создать и активировать виртуальное окружение следующими командами:
```bash
python -m venv .venv
source .venv/Scripts/activate
```

## Установка зависимостей
Установить необходимые зависимости одной командой:
```bash
pip3 install -r requirements.txt
```

## Запуск тестов
Команда для запуска всех тестов: 
```bash
python -m pytest -s
```

## Формирование Allure-отчета
Команда для запуска тестов и сохранения результатов:
```bash
pytest tests/ --alluredir=allure_results --clean-alluredir
```
Команда для генерации и просмотра временного отчёта без отдельного сохранения HTML-файлов:
```bash
allure serve allure_results
```
